# Neural-Informed Heston Pricing Under a Risk-Neutral Measure

This project develops a Python framework for learning and calibrating a Neural Stochastic Differential Equation under the risk-neutral measure, using the Heston model as a controlled stochastic-volatility benchmark. The model represents asset-price and latent-variance dynamics through a hybrid Heston–Neural SDE, retaining the Heston structure while allowing neural networks to learn data-supported deviations in variance drift or diffusion.
